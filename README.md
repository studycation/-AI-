
# 😻 PyTorch를 이용한 고양이 감정 예측 모델

이 프로젝트는 고양이 얼굴 이미지를 입력받아 **고양이의 감정**을 분류하는 AI 모델입니다.  
PyTorch를 이용해 MobileNetV2를 파인튜닝하였고, FastAPI , Docker , Google Cloud Run을 통해 누구나 웹에서 쉽게 사용할 수 있도록 배포했습니다.  

---

##  웹사이트
https://cat-emotion-app-1016958304774.asia-northeast3.run.app

브라우저에서 고양이 이미지를 업로드하면 실시간으로 감정을 예측해줍니다.  

---

##  기술 스택
- **Framework**: PyTorch, FastAPI  
- **Model**: MobileNetV2 (fine-tuned for cat emotions)  
- **Deployment**: Docker, Google Cloud Run  
- **Frontend**: HTML, JavaScript (fetch API)
